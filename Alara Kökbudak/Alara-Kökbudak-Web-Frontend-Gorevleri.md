# Alara Kökbudak - Web Ön Uç Görevleri

- **Satıcı Paneli:** Satıcıların gelen siparişleri görebileceği ana sayfa.
- **Durum Güncelleme:** Sipariş durumunu tek tıkla değiştirmeyi sağlayan butonlar ve API entegrasyonu.
- **Raporlama:** Geçmiş siparişlerin web arayüzünde detaylı dökümü ve filtreleme seçenekleri.
