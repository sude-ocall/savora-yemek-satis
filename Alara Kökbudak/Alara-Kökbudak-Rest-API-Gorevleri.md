# Alara Kökbudak - REST API Görevleri

- **Endpoint Geliştirme:** `/orders` ve `/payments` için gerekli CRUD operasyonlarının Node.js/Express (veya ilgili teknoloji) ile yazılması.
- **Veritabanı Entegrasyonu:** Siparişlerin ve kullanıcı ödeme yöntemlerinin DB modellerinin oluşturulması.
- **Güvenlik Katmanı:** Ödeme bilgilerinin hashlenmesi ve API uç noktalarının sadece yetkili kullanıcılara açılması.
