# Mobil Backend Görevleri

* **Auth Servisi:** Mobil uygulama üzerinden gelen kayıt isteklerinde JWT (Token) üretiminin sağlanması.
* **Adres Validasyonu:** Yeni adres eklenirken mobil cihazdan gelen GPS verilerinin doğrulanması.
* **Güvenlik Katmanı:** Şifre güncellendiğinde tüm aktif mobil oturumların sonlandırılması mantığının kurulması.
* **Performans:** Satıcı puanları listelenirken mobil veri tasarrufu için JSON çıktısının optimize edilmesi.
